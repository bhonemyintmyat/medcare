What this looks for

Four things that no single screen is placed to notice, because each one is a gap rather than a row: content nobody is recorded as owning, links that no longer lead anywhere, citations that are neither WHO nor the Ministry, and accounts that never got a profile.

Nothing here changes anything. Every finding links to the screen that owns it — the entry form for content, the accounts screen for people — because each of these can be correct, and which ones are is a judgement rather than a rule. The link check fetches every page a few at a time, so it is the slow one.
