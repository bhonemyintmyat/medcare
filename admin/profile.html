None of these three is editable here. Your role cannot be changed by you at all — the database refuses a self-change, so a control for it would only ever produce an error; one admin changes another’s role from accounts. Changing your email address means confirming the new one, which is a screen of its own rather than a field on this one.

Display name

Shown in the account menu, and to the editors on anything you publish or approve. It is not a username: it need not be unique, and nothing signs in with it.

Language

Which language MedCare opens in. This is a setting on this device, kept in your browser under mc-lang — it is not part of your account and it does not follow you to another machine. The public cookie settings page shows the same setting to readers.

Password

The current password is checked before anything is written. It is not required by the database — a signed-in session is enough for it — and it is asked for here because an admin screen left open on a shared desk is exactly the case that default protects nobody from.
