What this area cannot do

Not a list of buttons that are hidden. Every line here is a rule in the database, which refuses the request whatever the page in front of you looks like.

  • User accounts and roles. There is no policy anywhere letting an editor read another account or change anybody's role — including their own. That screen exists, and it is in the admin area.
  • Publishing, or changing a page that is already live. Submitting for review is where an editor's part ends. An admin is what puts a page in front of readers — and what changes one that is already there. To correct a live page, take it off the site first: the text is kept, and an admin puts it back. Taking one off needs nobody's approval, because a page you think is wrong should come down while you are still looking at it.
  • Deleting anything. Unpublishing takes a page off the site and keeps the row. There is no editor delete policy on any table, so a hard delete is refused rather than hidden.
  • Putting an emergency number on the page. Writing one and correcting one are an editor's. Publishing it is an admin's, like every other kind of content — and so is changing a number that is already on the page. If a live number is wrong, take it off the page: that needs nobody, and it is the right first move anyway.
  • Citing a source that is not WHO or the Myanmar Ministry of Health. The field checks as you type, and the database checks again when you save.
