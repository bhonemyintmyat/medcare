The pages

Four pages hang off the site footer and carry no medical advice: About MedCare, the terms, the privacy policy and the cookie settings. Each one ships its own copy inside its HTML file, and that copy is what readers see until something is saved here. Save prose for a page and it replaces the file’s copy; empty both boxes and the file’s copy comes back. Nothing here can leave a page blank.

You can read these and see exactly what the site says. Changing them is an admin’s: legal text is the one thing on this site an editor does not sign off. If something here is wrong, tell an admin — or send it through the reports queue so it is written down.

View the page

Shown in the list above. The page’s own heading is written into its HTML file, because a heading that arrives over the network has nothing to show while it is arriving.

Prose only: headings, paragraphs, lists, links, bold and italic. The site’s own furniture — the callout boxes, the panel of links on the About page, the setting cards on the cookie page — lives in the HTML file outside this text and keeps its styling. It cannot be typed or pasted in here; anything of that kind is reduced to the words inside it when the page is saved.

Written in one language only, that one is shown to everybody — the same rule the articles follow. Better the wrong language than an empty page.
