What a reader sees

These are the only two ways to reach the team that contact.html offers: up to four email addresses and up to four phone numbers. There is no contact form on that page and nothing is collected from a reader there, so what is typed below is the whole of it.

Up to 4.

Every mailbox a reader's message can arrive at. Give each one a label — General enquiries, Corrections — because a page listing four addresses with no word about which is which leaves the reader guessing where their message should go. This screen can only check that an address looks like one; whether mail sent there reaches a person is something no form can know, so send a test message and wait for a reply before trusting a change. A contact page pointing at an inbox nobody opens is worse than one with no address at all.

Up to 4.
With no address and no number saved, the Contact us page keeps the details written into the file it was published with. Nobody lands on a blank page — but the details a reader is given are then whatever was last deployed, not what is on this screen.
